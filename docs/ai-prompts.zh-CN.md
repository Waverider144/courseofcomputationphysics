# 合作写作 AI Prompt 集

[English](ai-prompts.md) | **简体中文** · [合作者指南](../CONTRIBUTING.zh-CN.md) · [LaTeX 模板](templates/README.md)

先向 AI 提供目标章节、相邻章节的总结、对应 preamble 及本次使用的参考材料，再使用“共同约束 + 一个任务”。方括号内由合作者填写。AI 输出由提交者核验；作者待补充区保持空白，直至作者确认。

## 共同约束

```text
你正在参与《计算物理学简明教程》的合作写作。读者具备数学分析、
线性代数、ODE/PDE 和基础数值计算知识，缺少 CFD/CEM/等离子体或 HPC 经验。

目标卷/章节：[填写]。
本次材料：[章节正文、前后依赖、preamble、参考资料或代码]。
允许修改的文件与范围：[填写]。
本次交付：[填写]。未请求文件修改时，先输出建议供我确认。

使用简洁、客观、连贯的学术语言。保留作者观点、章节结构、公式、
推导顺序、标签和引用；仅执行本次任务授权的改动。语言编辑不改变技术内容。
保留影响结论的条件，将自我评价式或防御式表达改为明确的研究范围、
省略项与检索入口。每次概念转向交代已有结果、剩余问题与下一步用途。

作者负责 WHY THIS、WHY NOW、WHAT MATTERS。
AI 负责推导、例子、计算、对比与实验。缺少作者动机时，标记并留出
【作者待补充：……】，不要编写答案；保留已有作者认可的补充。
技术事实、文献、系数、代码运行和性能数据均须可核验；
缺少来源时标为待核实，未运行时明确说明。区分假设、推导和测量。
沿用当前卷的符号、宏与中英文术语；发现错误或依赖顺序疑问时单列待确认项。
作者按卷署名，同一卷的中英文封面与 PDF 作者元数据保持一致。
修订过程说明用于当前对话或 PR，不另行生成仓库内的修订日志。
```

## 1. 提交章节提案

```text
基于已提供的三卷目录及相邻章节，为主题[主题]提出一页以内的章节方案。
先定位已有内容，说明这个问题为什么尚未解决，再写出：
1. 建议位置、读者已知结果与必须补齐的先备知识；
2. 本章解决的问题、一个核心思想、后续章节如何使用它；
3. 3–6 个小节及各自交付的关系、判断或计算；
4. 一个最小可检验例子、拟省略细节及精确的英文检索词；
5. 所需来源、代码/图表及中英文同步计划。
区分材料已支持的内容与需要作者决定的建模选择。
暂不写正文，不改变章节顺序。
```

## 2. 编辑 AI-native 界面层

```text
通读所附章节[范围]，先判断它在全书依赖链中的作用，再只编辑提示层。
章首写约 100–250 字的总结，说明已有结果、剩余问题、当前选择、
后续用途与核心思想，内容限于正文已有信息。

逐处区分：
A 动机与步骤均清楚：保持原文；
B 缺少模型选择或概念转向的动机：插入作者待填写区，不代写；
C 动机清楚但代数、例子或先备知识省略：写具体 AI 提问与后续变式。
每个 B 区域包含“潜在疑问”“作者补充”“核心概念联系”；
每个 C 区域写明当前符号、假设、起点、任务及可检查产物。
说明究竟略去什么，给出可直接检索的关键词。
沿用本卷已有宏，不把第 2 卷的 studentinput 当作作者输入区。
不重写正文，不修改任何公式；只在真正的转向处放置提示。
在当前对话末尾简报新增区域数量与尚待作者确认的位置。
```

## 3. 学术语言修订

```text
对[章节片段]进行语言修订，不扩展物理内容。
先识别每段的任务，再处理重复、代词指代、术语不一致和因果连接。
删去“这里不打算严谨讨论”“读者不必担心”等自我辩护，
改为明确的适用条件、保留结果、省略步骤和检索入口。
保留周期性、正定性、光滑性、求积精度等技术条件。
“显然”“自然得到”后若实际缺少动机，保留数学骨架并标记作者待补充，
不要通过编造一段解释来完成润色。
返回修改后的同格式文本；技术疑问在正文外单列。
```

## 4. 双语同步

```text
将[中文章节]译为英文，与[目标卷英文 preamble/相邻章]保持一致。
保持章节层级、数学符号、公式、label/ref/eqref/cite、习题和提示区一一对应；
先建立本章术语对照，再用自然、简洁的英文组织句子。
正文内的数学文字说明可翻译，数学关系、归一化、法向与符号约定不变。
沿用 CERK = continuous explicit Runge–Kutta。
作者待填写区仍为占位，已有作者补充照原义翻译。
逐项核对遗漏、额外假设、译义偏移和交叉引用。
返回英文 LaTeX；仅在当前对话说明待核实术语及实际执行的校验。
```

## 5. 数值实验或代码贡献

```text
为[章节中的算法或结论]设计最小可复现实验，复用[现有代码路径]。
先写出待检验主张、方程、初边值条件、离散与时间参数、误差/守恒指标
及预期可检验趋势；具体数值由运行产生，不预填测量值。
与[基线方法]采用相同物理问题、终止时间及可比精度。
给出依赖、运行命令、输出结构和验证测试。
分别记录实测时间、模型运算/流量和硬件校准，报告总成本与误差。
GPU 计时说明传输范围，MPI 说明进程布局和单机/跨节点范围。
执行仅限已授权的硬件和目录[填写]；权限未确认时只给方案。
最后列出实际运行的命令、结果、未运行项和实验能够支持的结论范围。
```

## 6. 独立技术与教学审阅

```text
审阅[目标章节及相邻依赖]，不直接编辑文件。
先列影响正确性的发现，再列教学与检索问题；每条包含位置、依据、
影响与最小修改建议。区分确定错误、合理疑问和缺少作者动机。
检查归一化、量纲、迹/法向、边界项、假设与结论的匹配，
以及连续/半离散/全离散结论和实测/模型成本是否混淆。
沿依赖链检查是否使用了尚未定义的对象、尚未给出的结果或循环引用。
检查 AI prompt 是否具体且能核验，是否代替了作者必须提供的动机。
核对中英文技术内容与代码/数据对应关系。
无依据时不要宣称正确或错误；明确说明尚未核验的来源与未执行的测试。
```

## 读者展开示例

以下示例以当前教材的数学骨架为起点，可直接放入对应的“你应该问 AI”区域。

**第 0 卷：GMRES 的残差。**

```text
对 Ax=b 使用左预条件 GMRES，沿用本章 M^{-1}。
从 Arnoldi 关系逐步推导小型最小二乘，并写出内部监测残差与 b-Ax。
用一个 3×3 对角缩放例子比较两者，核对每个范数与停止准则的含义。
继续：保持 A、b 不变，只缩放预条件器，哪些报告数值会改变？
```

**第 1 卷：边缘化与闭合。**

```text
沿用本章已定义的两粒子概率密度 varrho_2(z1,z2,t)，z_i=(x_i,v_i)，
从 g1(z1,t)=∫varrho_2 dz2 开始，逐步对 Liouville 方程积分。
取光滑成对势，并明确积分边界项消失所需的衰减条件。
保留平均相互作用项，指出它在哪里依赖双粒子分布。
不要预先假设独立性；区分精确边缘积分与另加的闭合假设。
继续：固定同一 g1，构造两个关联不同的联合分布，比较能由 g1 决定的统计量。
```

**第 2 卷：DG 频散。**

```text
沿用第 7 章的一维周期平流、精确积分、上风通量与 p=1 Legendre 基，
从局部弱形式计算 M、N、r、ell，再组装 Fourier–Bloch 符号。
使用 theta=kh 和 [u]=u^+-u^-，显式求两条特征分支，
通过 theta→0 识别物理分支，并复算附录的相速度误差。
继续：将空间特征值代入所选 RK 的稳定函数，分别报告空间与全离散误差。
```
